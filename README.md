
# Smart Hospital Management System

## DSA Mini Project

A C++ based hospital patient management system that uses a Priority Queue to prioritize patients according to their emergency levels.

## Features
- Add new patients
- Assign emergency priorities
- Treat the highest-priority patient first
- Display all waiting patients
- Show the next patient
- Count waiting patients

## DSA Concepts Used
- Priority Queue
- Max Heap
- Custom Comparator
- C++ STL

## Emergency Priority Levels
| Level | Priority |
|---|---|
| Low | 1 |
| Medium | 2 |
| High | 3 |
| Critical | 4 |

## Time Complexity
- Insertion: O(log n)
- Deletion: O(log n)
- Access top element: O(1)
- Display all: O(n log n)

## Technology
- C++
- Standard Template Library (STL)

## How to Run
Compile:
g++ main.cpp -o hospital

Run:
./hospital
